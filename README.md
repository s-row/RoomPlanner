# 프로젝트 정보
- 개발 인원: 3명
- 프로젝트 유형: Unity 기반 실시간 협업 가구 배치 프로젝트

# 프로젝트 개요
여러 사용자가 같은 공간에 접속하여 가구를 배치하고 조율할 수 있는 실시간 협업형 가구 배치 프로젝트입니다.  
사용자는 가구를 선택하여 배치하고, 위치 이동, 회전, 삭제, 크기 조절 등을 통해 공간을 구성할 수 있습니다.

# 사용 기술
- Unity
- C#
- Photon 에셋

# 담당 역할
제가 담당한 기능은 다음과 같습니다.
- 가구 이동 기능
- 가구 회전 및 삭제 기능
- 가구 크기 조절 기능

# 담당 기능 상세
- **이동 기능**: 생성된 가구를 선택해 원하는 위치로 이동할 수 있도록 구현했습니다.
- **회전 및 삭제 기능**: 가구의 위치를 보다 정밀하게 조절하기 위해 회전 기능을 추가하고, 필요 없는 가구는 삭제할 수 있도록 구현했습니다.
- **크기 조절 기능**: 배치한 가구의 사이즈를 조절할 수 있도록 구현했습니다.

# 주요 코드 설명
- `DraggableFurniture.cs`: 선택한 가구를 마우스로 드래그해 바닥 위에서 이동할 수 있도록 구현한 스크립트입니다.
- `FurnitureUI.cs`: 선택된 가구의 회전, 삭제, 크기 조절 UI 기능을 처리하는 스크립트입니다.
- `FurnitureSize.cs`: 입력값을 기준으로 가구의 가로/세로 크기를 조절하고 Photon을 통해 동기화하는 스크립트입니다.
- `FurnitureClick.cs`: 클릭한 가구의 Photon 소유권을 요청하고, 선택된 가구를 UI 조작 대상으로 연결하는 스크립트입니다.
- `FurnitureInfo.cs`: 가구의 초기 크기를 저장하여 크기 조절 기준값으로 사용하는 스크립트입니다.
- `EventTriggerListener.cs`: UI 버튼의 누름/뗌 이벤트를 처리하여 회전 버튼을 누르고 있는 동안 지속적으로 회전할 수 있게 하는 보조 스크립트입니다.

본 Repository는 전체 Unity 프로젝트가 아닌 팀 프로젝트 중 제가 담당한 기능 코드와 구현 내용을 정리한 포트폴리오용 저장소입니다.
